TechCrunch10月11日🔒需订阅01

亚马逊跟随微软放弃数据中心保密协议，AI 算力基础设施的社区信任成本正在上升

重点摘要
  • 亚马逊宣布在数据中心选址谈判中放弃保密协议，微软此前已作出与样承诺，标志著行业透明化压力上升。
  • 纽约与旧金山等城市已相继通过针对 AI 数据中心的建设暂停令，迫使业界以主动沟通换取建设许可。
  • 分析师指出，单靠公开资讯能否化解社区反弹仍是未知数，算力供给的中长期稳定性存在相应风险。
行业洞察

AI API 的算力稳定性受社区政治影响，中长期服务定价的可预期性存在潜在风险。

看详细内容（本站整理，约 730 字）

亚马逊于2026年10月3日在官方部落格AboutAmazon.com发表一篇题为「共同建设数据中心」的文章，正式宣布放弃在与地方政府谈判数据中心选址时惯用的保密协议（NDA）。此举紧随微软早先透过「Local Microsoft」部落格的类似公告，标志著两大云端巨头在公共关系策略上的明显转向——将「社区优先」作为获得建设许可的新叙事框架。

这一转变的直接背景是美国多地政府对大型数据中心的强力管制。纽约州已通过暂停令，冻结新建大型数据中心的审批，期限延续至州环境审查程序完成，预计约需一年；三藩市则在近期正式批准了数据中心禁令，被与会分析师形容为「相当讽刺」——这座以科技闻名的城市，却成为AI基础设施建设最明显的障碍之一。值得注意的是，纽约暂停令的措辞保留弹性空间，实质上是「研究期」，而非绝对禁止，地方政府仍可视情况逐案审批。

保密协议原本是科技企业与地方政府谈判的惯用工具。据TechCrunch记者Sean O'Kane分析，NDA的存在让企业得以在公众知晓前向政府提出更大范围的利益交换要求，例如税收优惠或配套基础设施承诺。他以Uber于2010年代中期在奥兰多附近与地方政府秘密达成的税务补贴协议作为历史参照，指出此类秘密谈判模式一旦曝光，往往引发严重的公众信任危机。分析师Rebecca Bellan则对暂停令能否真正延迟数据中心落地持怀疑态度：暂停令通常持续一至两年，而一座数据中心从获批到上线往往需要两至五年，两个时间轴并不重叠，因此政治阻力未必能转化为实质性的建设延误。

然而，分析师普遍认为放弃NDA只是「良好的第一步」，难以即时化解根本反对情绪。行业的沟通问题积累已久——O'Kane直言「业界在解释自身时做得极差」，企业长期采取「这是大势所趋，加入吧」的姿态，如今已开始转向主动提供正当性论述，这本身就是一种信号，说明社区阻力已具备足够的政治份量，迫使企业改变策略。对香港与台湾的营销从业者而言，这一趋势提示未来AI算力服务的采购与定价，将愈来愈受到数据中心选址成本、合规要求与社区关系成本的影响；企业在评估AI云端服务供应商的长期稳定性时，地缘政治与在地社区风险应纳入考量。

TechCrunch10月11日🔒需订阅02

PolyAI 与 Otter 高管：语音 AI 尚未达到「ChatGPT 时刻」，多语混合环境下的 ASR 准确率是落地主要障碍

重点摘要
  • PolyAI 技术长指出，ASR 在粤语、普通话与英语混合环境下的漏判率，导致下游全流程出错，是语音 AI 商业落地的最大障碍。
  • Otter 营销长强调，AI 语音代理必须主动告知用户其非人类身份，以符合消费者信任与合规要求。
  • 两位高管均认为语音 AI 尚未出现能够改变消费者习惯的决定性突破，类比 ChatGPT 对文字 AI 的影响。
行业洞察

评估语音客服或语音广告互动方案的代理商，应保留人工审核环节并纳入合规揭示条款。

看详细内容（本站整理，约 757 字）

PolyAI技术长Shawn Wen与Otter营销长Alex Gay于2026年10月接受TechCrunch记者Ivan Mehta采访，两人同时指出语音AI目前仍未出现如ChatGPT于2022年11月推出后所引发的消费者突破时刻。尽管投资者已向语音AI新创企业注入数十亿美元，模型厂商、企业客服、会议工具、AI语音输入等细分赛道均吸引到充裕资金，宣称具备接近人类对话能力的新工具每周都有发布，而市场营销诉求与真实应用效果之间的落差，却始终未能弥合。

两位高管各自点出不同技术瓶颈。Gay从会议转录的角度说明，自动语音识别（ASR）系统若在转录中遗漏关键词语，将导致整个下游处理管线失效——摘要错误、自动化行动触发错误，最终使用者因系统采取了错误行动而丧失信任，「一旦它开始执行错误的动作，你就会失去对平台的信任」。他特别强调语言能力的改善是当前最迫切的课题，多语混合环境（如粤语夹英语、普通话夹术语）对现有ASR系统的准确率构成系统性挑战，而非个案异常。Wen则从模型推理速度切入：目前全双工语音模型（即可同时说话与收听）在技术上已可实现，而推理速度仍不足以支撑自然对话的节奏，「下一个挑战是让推理变得足够快，使模型能够迅速提取答案」。

在监管与信任架构方面，两家公司采取了不同层次的披露策略。PolyAI要求所有企业客户在通话中向终端使用者明确告知对方正在与AI通话，这是其产品部署的强制前提；Otter的做法则更进一步，即使其AI机器人未出席会议，只要有录制行为发生，也会主动透过聊天功能通知所有与会者。两人均认为，主动披露是建立使用者信任的必要条件，而非法规压力下的被动合规举措。Wen另外提及，当语音品质达到足够水准后，使用者会开始建立信心，形成正向循环，而这一临界点目前仍未稳定触及。

Otter正在开发「数位分身」功能，让AI化身在会议中代表真实人物出席，并展现具情感表达力的人类化表情，Gay直言若这一层面做不到位，「那只是一个问答聊天机器人而已」。对香港与台湾的营销团队而言，现阶段部署语音AI于客服或电话营销需正视粤语、普通话与英语混用的ASR准确率限制；在简报、提案或内容生产流程中引入语音转文字工具前，应先在本地语言环境进行系统性验收测试，而非依赖厂商的通用基准数据。

量子位10月11日03

OpenAI 确认 GPT-4o 最早期 API 快照将于 10 月 23 日终止，仍运行旧版自动化工作流程的代理商面临中断风险

重点摘要
  • OpenAI 确认 gpt-4o-2024-05-13 API 快照将于 2026 年 10 月 23 日正式停止服务，距今仅剩 11 天。
  • 逾 2.4 万名用户联署要求保留，反映特定模型版本的「对话个性」对用户黏性有实质且难以量化的影响。
  • 代理商须立即核查内部自动化工作流程是否仍调用该版本，并在截止日前完成迁移以避免服务中断。
行业洞察

使用 gpt-4o-2024-05-13 API 的文案生成或客服自动化流程，11 天内若未迁移将出现服务中断。

看详细内容（约 816 字）

OpenAI 正式确认，旗下最早期的 GPT-4o API 快照版本 gpt-4o-2024-05-13 将于 2026 年 10 月 23 日终止服务，此日期距离公告发出仅余约 11 天。这一版本以其首次公开发布日期命名——2024 年 5 月 13 日，正是 OpenAI 执行长 Sam Altman 在社群媒体上以一个字「her」宣告 GPT-4o 问世的那一天，刻意致敬史蒂芬·史匹柏的科幻电影《云端情人》。然而近两年后，这个版本的 API 存取将正式画下句点，仍依赖此快照运行的自动化工作流程若未完成迁移，将面临服务中断。

OpenAI 援引使用数据为理据：截至退役日，选择 gpt-4o-2024-05-13 的日活用户比例仅余 0.1%，大部分用户已转移至 GPT-5.2。然而反对者指出，这个数字并不能真实反映用户意愿——ChatGPT 介面预设自动导向最新模型，免费用户更无法手动切换至旧版，使得「自愿迁移」与「被迫迁移」难以区分。一份研究分析约 1,500 篇与「Keep4o」社群相关的贴文，论文标题直白道出用户心声：《请不要杀死唯一仍有人情味的模型》（Please don't kill the only model that still feels human）。这场围绕 AI 模型「个性」的争议，在商业 API 政策讨论中实属罕见。

反对退役的声浪从 2025 年 4 月起就已成形。Change.org 上一份「请保留 GPT-4o」的联署请愿，截至报道发出时已累积 23,930 个签名；另有一份要求以非商业研究授权公开模型权重的联署，则仅获 472 人支持，显示大多数用户关注的是服务延续，而非开源取得。2026 年 2 月，约 30 名支持者甚至在 OpenAI 旧金山总部外守夜，进行象征性抗议。奥地利数位权利组织主导的 opensource4o 联盟亦于同年 7 月发表声明，要求 OpenAI 以 Apache 2.0 授权释出 2025 年 3 月版本的模型权重，理由是 2024 年系统安全卡评估该模型在网路安全、生物风险与模型自主性三项指标上均为低风险等级，具备公开条件。这场围绕旧版 AI 模型保存的运动，折射出用户对 AI「个性一致性」的高度重视，以及对厂商单方面终止服务的广泛不安。

对香港与大湾区广告代理商而言，这次退役揭示三个层面的实际风险。第一，工作流程层：若代理商的广告文案生成、受众分群、自动报告等自动化管线仍硬编码指定 gpt-4o-2024-05-13，10 月 23 日后即告中断，需在最后 11 天内完成版本切换与回归测试。第二，模型行为层：不同版本在语气、指令遵循方式与创意风格上存在差异，直接替换并不等同功能对等，测试成本不可忽视。第三，供应商依赖层：Anthropic 已于 2025 年 11 月承诺永久保存所有已公开发布的模型权重，并在模型退役前进行「退役访谈」——此举使其成为重视版本稳定性的代理商在评估 AI 供应商时的重要参考对象。代理商应在合约与技术架构上建立版本治理机制，预设迁移缓冲期，而非等到服务终止通知发出后才启动应对。

量子位10月11日04

矽谷 AI 算力成本一年飙升四成，代理商常用 AI 工具的订阅费上调压力已在累积

重点摘要
  • 矽谷 H100 GPU 租用单价一年内上涨约 40%，由每 GPU 每小时 1.70 美元升至 2.35 美元，算力供给持续紧张。
  • Anthropic 因被 Meta 拒绝算力合作后转与 SpaceX 达成协议，显示顶尖 AI 厂商之间的算力竞夺已影响商业合作格局。
  • 算力成本上升的压力正逐步转化为 AI API 与工具订阅的定价上行动力，代理商应在预算规划中预设弹性空间。
行业洞察

2027 年预算规划中应为 AI 工具订阅费用的上调预留弹性，并在合约谈判中加入费率审查条款。

看详细内容（约 741 字）

根据半导体研究机构 SemiAnalysis 于 2026 年 4 月发布的追踪报告，矽谷 H100 GPU 一年期租约的每小时费率，已从 2025 年 10 月的 1.70 美元攀升至 2026 年 3 月的 2.35 美元，五个月内涨幅接近 40%。这并非孤立的市场波动，而是源于全球顶尖 AI 实验室在模型研发、代理（Agent）式推理部署两条战线同步抢占算力所形成的结构性供需失衡。代理式 AI 应用不同於单次问答，每一个工作流可同时触发数十至数百条并行推理请求，令相同业务规模所需的算力远高于过往估算，直接加速了此波涨价周期。

AnthropicOpenAI 最强劲的竞争者之一，其算力困境已具体呈现于一段广为流传的内部叙述：执行长 Dario Amodei 曾向 Meta 洽询算力合作，却遭拒绝，随后转向 SpaceX 达成协议。根据公开信息，此次合作规模达 220,000 块 NVIDIA GPU、新增逾 300 MW 算力容量，SpaceX 在此交易中扮演的是 NVIDIA 晶片转售商角色。SpaceX 第三季度 AI 相关营收已达 25.61 亿美元，较前一季几近翻倍，较上年同期增长 247%，算力转售已成为其重要收入来源。同期，Google 以 27 亿美元将前 Transformer 论文作者 Noam Shazeer 从其创办的新创公司买回，而 Shazeer 其后选择转往 OpenAI，据称原因之一正是 Google 内部 GPU 配额不足。

算力市场的紧张态势正在催生新的中介业态。新创公司「San Francisco Compute」等机构以「全球算力勘探」模式运作，在农村鸡舍、偏远工业区等低租金地点搜寻闲置伺服器并整合转售；Y Combinator 则于今年 7 月为旗下投资组合公司另设专属 GPU 集群；加拿大风投 Radical Ventures 亦协助被投企业统筹协调供应商合约。各大云端平台已要求企业客户预缴合约总值 30% 的订金才能锁定长期供给，中小规模用户面临「抢购算力烧钱」与「预估不足错失成长窗口」的两难困境。

对香港及大湾区的代理商与品牌主而言，这波成本传导具有直接的预算意涵。Anthropic 此次与 SpaceX 的合作，明确目标之一是扩充 Claude Code 及 API 的使用上限，意味著算力成本最终仍将反映于订阅费率与 API 定价之中。当前业界普遍依赖的 AI 工具——无论是用于文案生成、广告受众分析或创意素材批量制作——其服务费率均承受上调压力。建议采购决策者在 2027 年度预算规划阶段，主动向各主要 AI 工具供应商确认未来 12 个月的定价走向，并评估是否透过年缴合约锁定现行费率；同时，对依赖 API 自建工作流的技术团队，应将算力成本列为专项变动预算项目，避免以静态成本假设低估实际支出。

Campaign Asia10月12日🔒需订阅05

东南亚雾霾威胁新加坡大奖赛品牌活化，气候不确定性成户外营销计划的新必答题

重点摘要
  • 东南亚季节性雾霾正威胁多个与新加坡大奖赛绑定的品牌户外活化项目，健康风险与活动扰乱相关的负面讨论占社交媒体整体声量的三分之一。
  • 事件凸显在东南亚及大湾区举办大型户外营销活动时，气候不确定性的风险管理已成必要议程，而非可选项。

同期另一值得关注的品牌整合案例，是 NikeSKIMS 于 2026 年 9 月 29 日在上海正式开出首个中国实体体验空间。这一由 Nike 与金·卡戴珊 Skims 品牌联名推出的系列，以「慢快闪」形式落地，计划在上海运营五个月。金·卡戴珊偕同母亲 Kris Jenner、姐姐 Khloé Kardashian 及三名子女亲赴现场，在开幕前的活动中造访动物园、品尝云南菜并游览迪士尼乐园，以家庭生活化的公关叙事放大品牌在中国社群媒体上的话题声量。空间设计采用品牌标志性配色，融入裸肤美学、弧形墙面、圆形沙发与穹顶天花，试衣间设有编号排队系统、前后镜与三种灯光模式，强化沉浸式零售体验。线上销售仅限品牌自有数位渠道，不透过第三方平台，以维护品牌定位与渠道管控。

对香港及大湾区的代理商而言，豆包山西文旅案提供了一个可直接借鉴的提案框架：在为旅游局、文博机构或主题景区客户构思 AI 整合方案时，视频通话式 AI 导览是兼具技术可行性与公众感知度的切入点，且官方背书有助于降低机构客户的采购决策阻力。NikeSKIMS 案则示范了如何以名人家族叙事驱动社群自然扩散——代理商可将其作为「明星出访即内容生产线」的操作范例，协助客户在无需大规模采买媒体曝光的前提下，透过真实生活场景制造持续的社群话题。
