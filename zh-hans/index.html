Google Gemini API release notes官方公告11月2日01

Google公布Gemini 2.5 API迁移安排，12月起自动转用其他模型

影响生意国际

发生什么Google于11月2日列出Gemini 2.5 Pro及Flash的弃用与迁移安排。

Marketing 影响以API支持文案、报表或客户流程的团队，需要重验输出与成本。

深入阅读：重点及分析
重点摘要
  • 12月1日起，Pro请求转至3.8 Flash，Flash请求转至3.5 Flash-Lite。
  • 转用后按目标模型费率收费。
建议下一步

列出仍用2.5的流程，在切换前以固定任务比较结果。

补充说明（约 117 字）

这项安排针对API模型识别码，并非所有Gemini使用者介面同时停用。Google指两款2.5模型已不能在AI Studio中选取，API自动转送则计划由12月1日起生效。迁移亦涉及函式呼叫及思考参数等兼容性变化。品牌团队宜要求技术供应商确认实际使用的模型、切换测试及费率，不能直接假设自动转送后输出与原本完全相同。

整理自：Google Gemini API release notes

Google Gemini API documentation官方公告10月30日02

工具补读：Google将Computer Use列为正式提供，执行环境仍由开发者搭建

要留意国际

发生什么Google在10月30日更新中，将Computer Use列为两款API的正式功能。

Marketing 影响希望自动处理网站工作的团队，需要把动作执行与审批一并纳入设计。

深入阅读：重点及分析
重点摘要
  • 模型读取萤幕截图，再提出点击及键盘操作。
  • 应用程式需自行执行动作及处理安全确认。
建议下一步

先以测试环境评估表格输入，记录错误与需要确认的操作。

补充说明（约 111 字）

Computer Use让模型根据萤幕截图提出介面操作，开发者仍须建立接收动作、执行操作及回传新截图的循环。Google把它列为Interactions及GenerateContent API的正式功能。官方文件亦提醒功能可能出错，应用程式需处理安全确认或封锁决定。正式提供不等于可以无人监督执行所有工作，亦不代表所有模型支持相同能力。

整理自：Google Gemini API documentation

Kaiser & Schulze / Search Engine Land补充来源 ↗媒体报道11月2日03

研究观察：美国样本中，ChatGPT广告每次访问收入低于Google搜索广告

影响生意国际

发生什么一份10月工作论文比较电商流量；11月2日的报道引起业界关注。

Marketing 影响媒体团队评估新渠道时，需要同时比较流量价值、媒体成本及归因方法。

深入阅读：重点及分析
重点摘要
  • 美国样本的每次访问收入分别为0.89及2.45美元。
  • 付费流量财务样本为102个网站，并非整体1,898站。
建议下一步

以自身投放数据比较获客成本及收入，避免直接套用研究平均值。

补充说明（约 121 字）

研究分析2025年6月至2026年8月的网站资料，整体自然引荐样本有1,898站，付费流量财务比较则使用102站。美国每次访问收入是合并样本数字，不能视为每个广告主都会出现相同差距。论文仍在审阅，资料以带来到访的最后一次点击作归因，未能完整反映其后或其他渠道的购买。这是观察研究，并非随机投放实验。

整理自：Kaiser & Schulze / Search Engine Land

Duda官方公告11月2日04

Duda整合电邮、短讯及自动化营销，部分AI接入仍分阶段推出

影响生意国际

发生什么Duda于11月2日整理DudaCon更新，将网站制作延伸至客户联系与营销管理。

Marketing 影响代客管理网站的团队，可评估能否在同一平台接续处理查询及客户跟进。

深入阅读：重点及分析
重点摘要
  • 内建联络人管理及多步骤营销流程。
  • 部分AI接入仍在推出，不能视为全部账户已可用。
建议下一步

先核对客户方案的电邮、短讯与自动化额度，再比较现有工具。

补充说明（约 122 字）

Duda的营销自动化功能把电邮、短讯、联络人资料及多步骤流程整合到网站平台。团队可按触发条件、等待时间及消息设定跟进工作。官方亦公布新的网站方案，额度随方案而异。AI Copilot及外部AI助理接入同步扩展，部分整合仍分阶段推出。公告没有证明转换率或成本必然改善，采用前需核对账户资格与方案限制。

整理自：Duda

Coveo官方公告10月29日05

电商补读：Coveo收购Anglera，把商品资料补全接入搜索

影响生意国际

发生什么Coveo于10月29日宣布收购Anglera，扩充电商商品资料能力。

Marketing 影响商品规格是否完整，会影响搜索团队能否准确描述产品差异。

深入阅读：重点及分析
重点摘要
  • Anglera从规格文件等来源撷取及标准化资料。
  • 现有客户继续使用Anglera；更深整合仍属计划。
建议下一步

先抽查高价值商品的尺寸、材质及兼容性资料与来源。

补充说明（约 121 字）

这宗收购把商品资料补全工具加入Coveo的商务服务。按公司描述，Anglera会从规格表、PDF及图片等来源撷取属性，按客户目录要求整理，并保留来源参考。Coveo Commerce客户将可通过附加服务使用相关能力。交易条款未公开，结合搜索行为与资料补全的更深整合仍待实现；公告中的成效案例不代表其他零售商可获相同结果。

MorningAI更新创意生成与排程标记预览

可即用国际

发生什么MorningAI于11月2日公布，Studio可在一次生成中提供多个创意方向。

Marketing 影响品牌团队可把素材选择与发帖前检查连成一个流程。

深入阅读：重点及分析
重点摘要
  • 可用产品页作参考，再调整成不同尺寸。

Aurora Mobile官方公告10月30日07

Modellix接入ComfyUI，让图像、视频与音讯串成工作流程

可即用国际

发生什么Aurora Mobile于10月30日公布Modellix.ai的ComfyUI整合。

Marketing 影响制作团队可把不同媒体步骤存成可重用流程，方便交接。

深入阅读：重点及分析
重点摘要

补充说明（约 110 字）

arXiv / EditAgent authors官方公告10月29日08

研究补读：EditAgent以专用工具与验证纪录处理图像修改

要留意国际

发生什么10月29日提交的EditAgent论文提出，按修改任务选工具，并附上验证纪录。

Marketing 影响创意团队可参考其把生成与检查分开的设计，而非一直重试同一工具。

深入阅读：重点及分析
重点摘要
  • 候选结果并行产生，再集中比较。
  • 研究涵盖两款开放权重编辑器及三个基准。
建议下一步

把品牌字样、产品细节及局部修改分列为验收项目。

补充说明（约 115 字）

EditAgent研究把图像编辑视为多步骤任务，按每一步需要选择通用或专用方法，并为候选结果附上验证纪录，供视觉语言模型判断。这类模型能同时处理图片与文字。论文属研究预印本，本报道只整理其方法与评估范围，并未确认已成为商用产品，也未实测品牌素材或宣称可节省制作成本。

Zocdoc官方公告10月28日10

案例补读：Zocdoc向AI代理开放美国医疗预约接入

要留意国际

发生什么Zocdoc于10月28日宣布向AI代理开放预约基建，并与Instinct合作。

Marketing 影响服务品牌可参考其把资料查询与可确认交易分开处理的方式。

深入阅读：重点及分析
重点摘要
  • 代理可查询医生、保险及可预约时段。
  • 预约前须取得病人明确同意。
建议下一步

盘点预约资料与授权步骤，先评估代理可读及可执行的界线。

补充说明（约 109 字）

这项美国案例提供了从AI查询走向预约的具体接入方式。Zocdoc列出MCP伺服器、REST API及深层链接，供代理连接服务；MCP是让AI与外部工具交换资料的协定。合作方Instinct将通过MCP接入。公告要求代理登记身份、保护资料及取得预约同意。服务只涵盖美国，不能据此推断香港可用或医疗结果有所改善。

整理自：Zocdoc
